# 🎵 AppMusicMobile

O **AppMusicMobile** é um aplicativo mobile desenvolvido em **.NET MAUI (C#)** focado em reprodução e experiência de usuário para música. O projeto conta com telas de apresentação, autenticação (Login e Cadastro) e navegação fluida entre páginas utilizando o ecossistema do **.NET Shell**.

---

## 📱 Telas do Aplicativo

* **Welcome / Onboarding:** Tela inicial com apresentação do app.
* **Opções de Acesso:** Escolha entre criar conta, login com e-mail ou redes sociais.
* **Login:** Autenticação de usuário com campos estilizados.
* **Cadastro:** Criação de nova conta de usuário.

---

## 🛠️ Tecnologias Utilizadas

* **[.NET MAUI 8.0](https://learn.microsoft.com/dotnet/maui/)** — Framework multiplataforma da Microsoft.
* **C# / XAML** — Linguagem de programação e marcação de interface.
* **.NET Shell Navigation** — Gerenciamento de rotas e pilha de navegação.
* **Android Emulator** — Plataforma principal de testes e execução.

---

## ⚙️ Funcionalidades e Destaques

* UI customizada com suporte a modo escuro (Dark Theme).
* Campos de entrada de texto (`Entry`) estilizados em containers customizados (`Border`).
* Mapeamento de rotas registrado via `Routing.RegisterRoute`.
* Navegação relativa entre páginas sem perda de pilha de histórico.
